# Triage labels

For local tickets, use these values in the `Status:` field.

| Role | Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer must evaluate the issue |
| needs-info | needs-info | Waiting for information from the reporter |
| ready-for-agent | ready-for-agent | Fully specified and ready for an agent |
| ready-for-human | ready-for-human | Requires human implementation |
| wontfix | wontfix | Will not be actioned |

Wayfinding tickets use the lifecycle states documented in
`issue-tracker.md`.
